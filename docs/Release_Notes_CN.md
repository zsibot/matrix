# MATRiX v1.1.1 发布与升级说明

[中文 README](README_CN.md) | [English](Release_Notes.md)

## 版本依据

本说明于 2026-09-21 按目录内 2026-09-21 15:08（北京时间）打包的 Linux x86_64 运行文件、实际配置、传感器预设和内置运控资源记录更新。运行程序与 `Engine/`、模型和插件作为整体使用；当前开发源码中的未打包改动不自动属于本版本。

## 本次发布内容

- 初始模型为 `xgw2`，模型路径整理为相对于 `UeSim/` 的 `Content/model/xgw2/xgw2.xml`，移动整个目录后不再依赖开发机路径。
- 保留 `inside_mc=true`、`network_mode=standalone`、`sensor_sync_mode=true`。当前活动配置包含 IMU、Odom、GPS、RGB、Depth 和 Airy 六个传感器，与 `config_default.json` 一致；默认开启同步模式。进入仿真并创建机器人后再接收数据，其他方案需要加载并应用。
- 随包方案包括 RGB、深度、红外、鱼眼、全景、云台、IMU、Odom、GPS、Airy 和 MID360；`config_data.json` 使用 MID360，Airy/MID360 的后端统一使用 `backend` 字段。GPU 实际启用情况以运行日志为准。
- 随包内置运控资源记录了 2026-09-08 的 0.6.6 集成，包括 XXG 步态更新、XG2 Passive 和 XGW2 起身轮关节锁定；模型权重存在不表示所有策略均已接入。详见 [运动控制](Motion_Control_CN.md)。
- 同步透视点云投影的畸变有效分支过滤，避免画面外射线被高阶畸变折回图像；加入四路鱼眼投影与世界包围盒叠加工具。
- 新版 `visualize_zenoh_bbox.py` 改为分类 XY 俯视图，显示车辆、行人、速度和完整目标详情。原固定范围 `_2d.py` 保留兼容入口。
- 加入原始 Zenoh 消息录制、离线预览和回放工具，配套辅助模块完整随包分发。
- 本次重打包已包含 `config_semantic.json`（语义相机）和 `config_rgb_semantic.json`（同位姿 RGB/语义配对）。输出无损类别 ID PNG；使用 `zenoh_sensor_receiver.py` 可按类别着色查看。语义相机不在默认六传感器方案中，需要另行选择并应用。
- 启动脚本支持带空格的目录和符号链接，检查二进制是否存在，完整转发参数并返回进程退出码；生成对象脚本默认目标改为本机。
- 提供 Python 依赖文件和工具清单，重写中英文默认配置、传感器启用和迁移说明。

## 从旧版本迁移

1. 使用完整的 v1.1.1 运行目录，不混用旧 UeSim 二进制、Engine、插件动态库和模型。
2. 备份原配置，逐项迁移模型、传感器外参、topic 和网络设置；不要直接覆盖新版整个 `config/`。
3. 保留需要的内置/独立运控模式。独立 `robot_mc` 不随本目录分发；外部版本、机型参数和依赖以另行下载的 README 为准。
4. 默认六传感器方案可直接用于数据检查；切换到 RGB/语义配对等其他方案后，重新核对活动配置与订阅 topic。
5. 更新地图列表，下载与 v1.1.1 匹配的 DLC。旧地图兼容性需按地图发布方说明核对，不能只凭文件扩展名判断。
6. 按 [工具清单](../Tools/README.md) 安装依赖；复制工具时连同辅助模块一起复制。

主配置中的默认关键字段：

```json
{
  "mujoco_model": "Content/model/xgw2/xgw2.xml",
  "inside_mc": true,
  "network_mode": "standalone",
  "sensor_sync_mode": true,
  "zenoh_router": "tcp/0.0.0.0:7447"
}
```

这些字段位于顶层 `robot` 对象内；此片段省略已配置的六个传感器，完整内容以随包配置为准。预设文件 `config_v1.0.12_zgwt.json` 保留历史名称，不表示发布目录仍为旧版本。

## 验证边界

工具的 `--help` 和 `--check-only` 可离线核对参数和标定，但不验证 GPU 驱动、实际地图加载、实时网络吞吐或机器人动作。本次文档与工具整理没有重新编译或替换仿真二进制；完整运行效果仍需在目标机器上启动验证。

本次离线核对已通过：12 个命令行入口的 `--help`、默认/MID360/四路鱼眼方案投影配置检查、30 项接收解析与录制回放回归测试、文档相对链接与配置 JSON 检查。启动脚本使用替身程序验证了空格路径、符号链接、参数传递及退出码；未启动真实 GPU 仿真。
